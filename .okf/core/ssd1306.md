# Role

Monochrome OLED driver for the Solomon Systech SSD1306. Extends `GeneralPurposeIO\Circuits\DisplayPanel`, implements `BootSequence` and tubes `Contracts\Panels\MonochromeDisplay` (PanelDevice transmit surface for `Panel::wrap`).[^ic]

# Attributes

```php
#[IntegratedCircuit('I2C', ['SPI', 'DigitalIO'])]
#[Pinout(
    ['I2C' => ['driver', 'device', 'slave']],
    ['SPI' => ['driver', 'device', 'chip_select'], 'DigitalIO' => ['driver', 'device', 'dc', 'rst']],
)]
```

Index-aligned with gpio-framework `circuit:make-profile` / package `ssd1306:make-profile` prompts.[^ic]

# Factories

| Factory | Primary args | Notes |
|---------|--------------|-------|
| `SSD1306::i2c($device, $adapter, $slave, …)` | device, adapter, slave (default `SSD1306I2CAddress::SAO_GROUNDED`) | Builds via `I2C::adapter` → `fromI2CBus` |
| `SSD1306::spi($spi_device, $chip_select, $digital_device, $dc_pin, $rst_pin, $spi_adapter, $digital_adapter, …)` | SPI + DigitalIO pins | Mode 3 / 1 MHz; if SPI bus `canServeDigitalPins()`, DC/RST come from that bus |
| `fromI2CBus` / `fromSPIBus` | Already-open buses/pins | Lower-level entry |

Shared panel knobs (defaults): `width` 128, `height` 64, `contrast` 191, `boot_now` true, horizontal addressing.[^ic]

# Tubes framebuffer contract

Uses **tubes** `FormatSpec` / `DumpedBuffer` — not Fabricate Displays/Framebuffers.

- `formatSpec()` / `generateFormatSpec()` → `PixelFormat::MONO_VERTICAL_PAGE`, `BitDepth::B1`, `ScanDirection::TOP_TO_BOTTOM`, `BitOrder::LSB_FIRST`, `PageAxis::VERTICAL` for horizontal/page addressing.
- `transmit(DumpedBuffer $frame)` sets the address window then clocks `raw_data` through the carrier transport (chunked by `max_packet_size`).[^ic]

# Boot and breakouts

- Boot sequence uses `GeneralPurposeIO\Contracts\Circuits\BootScaffolding` (`_boot()` in `SSD1306InternalAPI`).[^internal-api]
- Register-style breakouts extend `GeneralPurposeIO\Circuits\DataRegister` (e.g. charge pump, COM pins, segment remap, data clock).[^data-clock]
- Wire path is `SSD1306CarrierTransport` (I2C slave **or** SPI + DC/RST).[^transport]

# Public control surface (API trait)

`displayOn` / `displayOff`, contrast, invert, segment/COM remap, addressing mode, charge pump, precharge, fill overlay, scroll off, address window + `data()` for raw bytes — see `SSD1306API`.[^api]
